# 🍔 Swiggy Analytics Dashboard

## 📌 Project Overview
This project is an interactive Tableau dashboard created using a real-world Swiggy restaurant dataset from Kaggle.

The dashboard provides insights into:
- Restaurant ratings
- Food categories
- Expensive restaurants
- Top cities
- Average pricing
- Customer ratings

---

## 🛠 Tools Used
- Tableau Public
- Kaggle Dataset
- Data Visualization
- Dashboard Design

---

## 📊 Dashboard Features
- Interactive Filters
- KPI Cards
- Top Rated Restaurants
- Top Food Categories
- City-wise Analysis
- Restaurant Price Analysis

---

## 🔥 Key Insights
- Jaipur has the highest restaurant count
- Desserts and beverages are the most popular categories
- Average restaurant rating is 2.6
- Premium restaurants tend to receive better ratings
